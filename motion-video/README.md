# وفّرها صح — فيديو موشن جرافيك اجتماعي

مشروع Remotion عمودي 9:16 (1080×1920)، 30 إطار/ثانية، مدة 18 ثانية.

لتشغيل المعاينة: `npm install` ثم `npm run start`.
لتصدير MP4: `npm run render`.

ملاحظة: أضف الصور الأصلية إلى `public/assets` قبل التصدير. أرفق نص التعليق الصوتي وسيناريوه في الفيديو، لكن يلزم تسجيل الصوت وإضافته قبل التصدير النهائي.
